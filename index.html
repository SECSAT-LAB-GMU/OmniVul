OmniVul: A Holistic, Multi-Turn Conversational Benchmark for LLM-Based Vulnerability Assessment

Anonymous Authors | KDD 2026 Submission #91

Abstract

With more than 20,000 Common Vulnerabilities and Exposures (CVEs) reported annually, software vulnerabilities represent a critical cybersecurity challenge. Existing benchmarks are often narrow, context-light, and single-turn, making them less suitable for realistic LLM-based analyst workflows. OmniVul addresses this by providing a comprehensive multi-turn benchmark with 2,000 CVEs and question-answer pairs across 23 attributes, covering detection, code localization, root cause analysis, and patch suggestion.

The repository includes an end-to-end workflow for data collection, portfolio construction, QA generation using RAG, and quality filtering using LLM-as-a-Judge with conformal prediction calibration.

Scale

2,000 CVEs collected and curated for benchmark construction.

Attribute Coverage

23 vulnerability attributes for richer analysis than single-turn QA.

Repository Sections

Section 3 (pipeline), Section 4 (data/results), Section 5 (SOTA LLM evaluation).

Vulnerability detection, CVE identification, and attribute QA correctness.

Pipeline Overview

Section 3 Workflow

  • Step 1: Collect vulnerability data from NVD and other sources, then build CVE portfolios (`Section 3/step_1`).
  • Step 2: Generate QA pairs from portfolios using a RAG pipeline (`Section 3/step_2/gen_qa_cves.py`).
  • Step 3: Evaluate with LLM-as-a-Judge and conformal prediction calibration (`Section 3/step_3`).

Execution requires installing dependencies from requirements.txt. Step 2 and Step 3 require setting an OpenAI API key in project constants.

pip install -r requirements.txt
python "Section 3/step_1/portfolio_construction.py"
python "Section 3/step_2/gen_qa_cves.py"
python "Section 3/step_3/evaluate_rag.py"
